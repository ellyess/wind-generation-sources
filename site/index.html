Notes on this sheet

  1. Observed output only. Every source here is metered, settled, certified or reported by its publisher. Simulated series, such as renewables.ninja, EMHIRES or capacity factors computed from reanalysis, have other homes and are left out.
  2. Licences are read, not inferred. Each licence was read on the publisher's own page on the date shown. Until it has been read, re-hosting stays Unclear.
  3. Every trap cites its evidence. A trap is a property of the source: a mislabelled column, a silent change, a gap. Each one links to the documentation, issue or audit that shows it.
  4. Links, not copies. The catalogue holds metadata only. It never re-hosts a publisher's data.
  5. One file per source. To add or correct an entry, edit its YAML file and open a pull request. The validator checks the schema and these rules.

Wind Generation Sources is maintained by Ellyess Benmoufok. Entries are licensed CC BY 4.0, code MIT. Publishers' data stay under their own terms.
